# ⚡ Makefile Commander (просто `m`)

[🇷🇺 Русский](README.RU.md) | [🇬🇧 English](README.md)

**Makefile Commander** — это сверхбыстрый, легковесный интерактивный CLI-интерфейс для вашего `Makefile`, написанный на чистом Node.js. 

🚀 **Ноль внешних зависимостей.** Нужна только установленная Node.js (v12+).
🎨 **Красивый TTY UI** с поддержкой категорий, мгновенным поиском на лету, удобной навигацией по стрелочкам и чистым выводом в терминал.

![Makefile Commander](preview.gif)

---

### 🔥 Почему это чертовски удобно?

* **Мгновенный поиск**: Просто начните вводить текст — утилита моментально отфильтрует команды по имени, категории или тексту описания.
* **Группировка по категориям**: Наведите порядок в своем `Makefile`. Разделяйте команды по логическим блокам (`Docker`, `Database`, `Deploy` и т.д.).
* **Интерактивные команды работают без проблем**: Запуск логов в реальном времени (например, `docker compose logs -f`) или интерактивных утилит внутри ваших команд не ломает отображение терминала — всё работает ровно так же, как если бы вы запустили команду напрямую.
* **Никакого мусора**: Утилита аккуратно стирает свой интерфейс из терминала перед выполнением команды и после выхода, сохраняя историю вашего терминала в первозданном виде.

### 🛠️ Быстрая установка (подключаем как `m`)

Чтобы вызывать утилиту одной буквой `m` из любой директории вашего компьютера, скопируйте файл в системный или пользовательский каталог исполняемых файлов:

#### Вариант 1: Системная установка (для всех пользователей)
```bash
sudo cp make.js /usr/local/bin/m && sudo chmod +x /usr/local/bin/m
```

#### Вариант 2: Локальная установка (только для вашего пользователя)
```bash
mkdir -p ~/.local/bin
cp make.js ~/.local/bin/m
chmod +x ~/.local/bin/m
```
*💡 Не забудьте убедиться, что путь `~/.local/bin` добавлен в вашу переменную `$PATH` (обычно это настраивается в файлах `~/.bashrc`, `~/.zshrc` или `~/.profile` строкой `export PATH="$HOME/.local/bin:$PATH"`).*

### ✍️ Как разметить ваш `Makefile`

Makefile Commander автоматически распознает цели (targets) и комментарии. Вы можете оформлять их двумя способами:

#### Способ 1: Встроенные комментарии (через `##`)
Самый лаконичный вариант. Описание пишется прямо на строке цели через двойной символ решётки:
```makefile
up: ## Запустить локальное dev-окружение в фоне
	docker compose up -d

down: ## Остановить контейнеры и очистить окружение
	docker compose down
```

#### Способ 2: Категории и многострочные описания
Для крупных проектов вы можете логически группировать команды с помощью тега `@category`. Любые комментарии непосредственно перед целью станут её описанием:

```makefile
# @category App Development

# Запустить сборку фронтенда и бэкенда в продакшн режиме
# с предварительной очисткой кэша
build:
	npm run build

# @category Docker Local

# Поднять базу данных PostgreSQL локально
db-up:
	docker compose up -d postgres

# Остановить PostgreSQL и стереть сохраненные данные
db-clean:
	docker compose down -v
```

### 🎮 Использование

Просто введите `m` в любой директории, где лежит `Makefile`:
```bash
m
```

#### Управление в UI:
* `[↑ / ↓]` или `[Ctrl+P / Ctrl+N]` — Перемещение по списку команд.
* `Любые символы` — Поиск и фильтрация в реальном времени.
* `[Backspace]` — Удаление символа в строке поиска.
* `[Enter]` — Запуск выбранной команды.
* `[Esc]` или `[Ctrl+C]` — Выход из утилиты.

#### Мгновенный запуск в обход меню
Если вы уже помните название команды, введите её аргументом:
```bash
m build
```
* Если команда `build` существует в вашем `Makefile`, она запустится **сразу**, минуя интерактивное меню.
* Если такой команды нет, автоматически откроется интерактивный UI, а введенное слово подставится в поисковую строку как фильтр.

### 📦 Требования
* **Node.js** v12.0.0 или новее.
* **Make** (установлен по умолчанию на macOS и большинстве дистрибутивов Linux).
* Никаких `npm install` и `package.json` — скрипт работает прямо из коробки!
